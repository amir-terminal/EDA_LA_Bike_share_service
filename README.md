# Los Angeles Bike Share Exploratory Analysis

CSMAD coursework exploring Los Angeles Metro Bike Share trip data. The repository includes a Jupyter notebook, its rendered HTML export, and the CSV used for the analysis.

| File | Use |
| --- | --- |
| [Coursework notebook](Course%20work%201/33824284_CSMAD_Coursework.ipynb) | Inspect the analysis code and saved outputs |
| [HTML report](Course%20work%201/33824284_CSMAD_Coursework.html) | Download and open in a browser to read the report |
| [Metro trip data](Course%20work%201/metro.csv) | Input dataset |

To work with the notebook, launch Jupyter from the coursework folder so the dataset is available next to it.

~~~bash
cd "Course work 1"
python -m notebook 33824284_CSMAD_Coursework.ipynb
~~~

Install Jupyter and the analysis libraries imported in the notebook before rerunning cells. The HTML export provides a copy of the coursework output for reading without a Python environment.
